# 🌍 Favourite Places in India

## 📌 About the Project

Favourite Places in India is a frontend practice project developed using **HTML5, CSS3 and Tailwind CSS**.

This project showcases famous tourist attractions, historical monuments and temples across India with images and short descriptions.

The project is implemented in two versions:
- HTML + CSS
- HTML + Tailwind CSS

## 🛠️ Technologies Used

- HTML5
- CSS3
- Tailwind CSS
- Visual Studio Code
- Live Server

## ✨ Features

- Displays famous places in India.
- Attractive gradient background.
- Individual cards for each place.
- Images with descriptions.
- Flexbox layout.
- Consistent spacing between cards.
- Rounded corners and shadow effects.
- Responsive layout.

## 🚀 How to Run the Project

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder in VS Code.

3. To run the CSS version, open `CSS-Version/index.html`.

4. To run the Tailwind version, open `Tailwind-Version/index.html`.

5. Install the Live Server extension in VS Code.

6. Right-click the HTML file and select **Open with Live Server**.

7. View the webpage in your browser.

**Note:** The Tailwind version uses the Tailwind CSS browser CDN, so an internet connection is required.
